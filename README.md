# E5 增强包 — 热更新（整合版）

一个包，两项改动，一次装完。在**已运行 OpenWrt 的 E5**（Unisoc T157/T158）上执行，**不重刷机、不重编内核**。

| # | 改动 | 效果 | 生效方式 |
|---|---|---|---|
| **A** | **充电模式开关** | LuCI 出现「服务 → 充电模式」，控制插充电器开机行为 | 需 `reboot` 一次 |
| **B** | **AT 终端增强** | 新增 IMEI 命令组；每条快捷命令带中文说明；**点击只填入、发送需确认** | 浏览器强制刷新即可 |

只写 rootfs 用户态文件，可一键卸载回滚。原理与背景见下方各节。

---

## A. 充电模式开关

控制 **「插着充电器开机」** 时的行为：

| 开关值 | 行为 |
|---|---|
| **1（默认）** | 插充电器 → **直接进入 OpenWrt**（E5 的历史默认） |
| **0** | 插充电器 → **停在充电界面**，长按电源键 1.5 秒才继续；中途拔充电器也会继续启动 |

只影响**充电器触发的那一次**启动，不影响正常按键开机。

命令行改（也可在 LuCI 页面点）：

```sh
uci set e5-charge-mode.main.enabled='0' && uci commit   # 停在充电界面
uci set e5-charge-mode.main.enabled='1' && uci commit   # 直接进系统
```

---

## B. AT 终端增强

1. **新增分组「IMEI 修改」**：

   | 命令 | 说明 |
   |---|---|
   | `AT+SPIMEI?` | 查询当前 IMEI（串号） |
   | `AT+SPIMEI=0,"改为你的串号"` | 写入 IMEI：`0`=卡槽 1，把引号内换成你的 15 位串号 |

   点这个芯片时，**「改为你的串号」会被自动选中**，直接敲键盘就替换掉，不用手工拖选。
   没替换就点「发送」会被拦下并提示，不会把占位符原样发给模块。

2. **全部 28 条快捷命令都加了中文说明**——鼠标**悬停**（手机端**长按**）时，
   说明显示在按钮下方，同时写入 `title` 属性（浏览器原生 tooltip 也能看到）。

   覆盖：基础(8) / 注册信号(7) / 承载(4) / 工程模式(7) / IMEI 修改(2)，
   例如 `AT+CSQ` → 查询信号强度：第一个值为 RSSI（0~31，99=未知）。

3. **点击只填入、不发送**——点快捷命令或右侧「会话历史」时，命令只被填进输入框
   （自动聚焦、光标落在末尾，方便补参数），**必须再点「发送」按钮或按 Enter 才会真正执行**。

   这样改是为了防误触：`AT+SPIMEI=0,"..."` 属于写号命令，以前点一下就出去了。
   现在流程是「点命令 → 确认/改串号 → 点发送」。

## 安装

```sh
# 1. 传到设备
scp -r e5-hotupdate root@192.168.9.1:/tmp/

# 2. 在设备上执行（SSH 或串口，root）
cd /tmp/e5-hotupdate && sh install.sh
```

装完：

- **A**：执行 `reboot`，之后进 LuCI → **服务 → 充电模式**
- **B**：浏览器按 **Ctrl+F5** 强制刷新，打开 AT 终端

### 只装其中一项

```sh
sh install.sh --charge     # 只装充电模式开关
sh install.sh --at         # 只装 AT 终端增强
```

## 卸载 / 回滚

```sh
cd /tmp/e5-hotupdate && sh install.sh --uninstall
```

- 删除 A 的**全部代码文件**与自启软链，但 `/etc/config/e5-charge-mode` **保留**（避免误删你的开关设置）
- B 自动**还原安装前的原始页面**（备份在 `/root/at.js.bak.<时间戳>`，
  重复安装不会覆盖这份原始备份，始终能回到最初版本）
- 卸载后可随时重新 `sh install.sh`，回滚链不会断
